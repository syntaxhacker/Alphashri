## Key Insights
- **OR duration is irrelevant on 1-HOUR bars**: OR_MIN ∈ {5,10,15,60} all produce identical results — the pre-OR window (9:15–open+OR_MIN) only ever contains the single 9:15 bar (next bar is 10:15). Noted as expected.
- **EOD exit is effectively a no-op sweep**: on hourly bars timestamps are at :15 marks (555,615,...,915). EOD 870/885/900 all resolve to the same 15:15 bar exit (next bar ≥ threshold is always 915). No intraday EOD granularity exists.
- **The "edge" is ONE trade.** 2026-06-19 (entry 480.00, TP fill 488.59) contributes ~+717 net of ~+578 total. Every config with 5-7 trades shares this single winner.
- **PF is maximized by collapsing SL to noise levels** (0.01-0.05%): losses shrink toward zero while the winner is untouched → PF climbs monotonically (0.28 → 3.51). This is a degenerate curve-fit, NOT a tradable edge.
- **TP is curve-fit to the winner's exact high**: 6/19 high=488.60 → TP ceiling = 1.79% of entry. TP=1.79 → PF=3.51; TP=1.80 (1 bp past) → PF collapses to 0.0.
- **Robustness check FAILED**: buffer 0.6 (vs best 0.5) filters out the 6/19 entry → PF drops to 0.0. Winner is razor-thin.
- **Realistic regimes lose**: SL=0.5/TP=2.0 → PF=0.34; SL=1.0/TP=3.0 → PF=0.32; baseline SL=1.0/TP=1.5 → PF=0.28. Enabling shorts floods 23 extra losers → PF=0.63 at 30 trades.
- **Verdict**: On 1-HOUR NEWGEN, ORB generates ~5-7 trades/quarter with no genuine edge. The best PF=3.51 config (SL=0.01, TP=1.79, buf=0.5, cd=2) is not production-usable; it is defined by a single day's move and breaks on 1bp perturbations.
