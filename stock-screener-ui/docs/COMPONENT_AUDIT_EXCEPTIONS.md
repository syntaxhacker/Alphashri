# Component audit exceptions

`docs/COMPONENT_AUDIT.md` counts a module as "storied" only when a story imports one of its own exported names. The modules below are audited but have no standalone story on purpose: they are context providers, error boundaries, chart adapters or table-internal renderers with no independent visual state, or they need a Router / fetch lifecycle that a static catalog cannot supply. No fake specimen was added for them.

Where a catalog surface does exercise the surrounding UI, it is named below; otherwise the page-level owner and its co-located test are named. These are not claims that the module renders in Storybook.

| Module | Why no standalone story | Owning story / family (or page owner) |
|---|---|---|
| `components/common/ChartDockOutlet.tsx` | Empty mount node registered with the symbol dock; nothing to see until a provider renders into it. | Symbol dock surface — `src/components/common/SymbolDockProvider.test.tsx` mounts it with the outlet; the real outlet sits in the market screener (`MarketScreenerPanel.tsx`). The symbol affordance itself is staged in `Design System/Components/App/SymbolLink`. |
| `components/common/ChartErrorBoundary.tsx` | Only its fallback is visible, and only after a chart render throws. A story would have to throw on purpose to show a static message. | Error-state pattern in `Design System/Components/App/ErrorBoundary`; the boundary's own fallback is covered by `ChartErrorBoundary.test.tsx`. |
| `components/common/ClickableSymbol.tsx` | `SymbolLink` + `useNavigate()` + symbol dock; it needs a Router and a provider, and has no appearance of its own. | `Design System/Components/App/SymbolLink` stages the rendered affordance and explicitly excludes this wrapper; navigation/dock behaviour lives in `ClickableSymbol.test.tsx`. |
| `components/common/ColumnPicker.tsx` | Portal-anchored control owned by the table toolbar; its open/close position depends on a real trigger rect and scroll container. | `Design System/Components/App/TanStackTable` (the table surface that hosts it); interactions in `ColumnPicker.test.tsx`. |
| `components/common/CorrelationHeatmap.tsx` | ECharts matrix driven by an API payload and a colour scheme; the heatmap is a page chart, not a design-system primitive. | Sector correlation tab (`src/components/sector/SectorCorrelationTab.tsx`) and `CorrelationHeatmap.test.tsx`. No catalog family owns sector charts. |
| `components/common/EChart.tsx` | Thin lazy-ECharts lifecycle wrapper (init / setOption / resize / dispose); no markup or props that produce a distinct visual state. | Any chart specimen using the same loader — `Design System/Components/App/ChartPreviews`; lifecycle guards in `EChart.test.tsx`. |
| `components/common/PanelModal.tsx` | Panel chrome over `@/ui` Modal: the overlay, focus cycle and dismissal all belong to Modal. | `Design System/Components/Overlay/Modal` and the `Design System/Overlay` family landing; sizing/drawer cases in `PanelModal.test.tsx`. |
| `components/common/PreviewChartProvider.tsx` | Context + fetch orchestration; it renders no UI of its own and needs `useNavigate()` and notifications. | `Design System/Components/App/ChartPreviews` stages the two panels it renders (`HoverPreview`, `ExpandedPanel`); provider wiring in `PreviewChartProvider.test.tsx`. |
| `components/common/SymbolAutocomplete.tsx` | Search input whose suggestions come from an app-wide symbol registry; useful states require real lookup data. | Inputs family (`Design System/Inputs`) for the text-input shell; the options simulator owns the real instance. Suggestion/menu behaviour in `SymbolAutocomplete.test.tsx`. |
| `components/common/SymbolDockProvider.tsx` | Context provider with no standalone UI; the dock appears only through consumer portals and a Router. | Symbol-link surface (`Design System/Components/App/SymbolLink`) and `SymbolDockProvider.test.tsx`; mounted app-wide in `src/App.tsx`. |
| `components/common/table/renderers.tsx` | Internal header/body/cell render functions called with a table render context; they are not components a story can mount on its own. | `Design System/Components/App/TanStackTable` and `Design System/Components/App/TableCells` stage the composed table cells. |
