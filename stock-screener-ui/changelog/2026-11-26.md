# 2026-11-26

## Added

- In-memory DB query benchmark harness (`scripts/perf/db_query_bench.py`) with structural tests, so query cost can be measured without touching the live SQLite DB.
- Covering indexes for instruments and replay configs, plus the migration that installs them.
- Regression suites for FastAPI route prebuild, the new DB indexes, and analytics column projections.
- Evidence set `docs/screenshots/symbol-format-ui/` (24 PNGs, 12 states × 1600/390); visual grade independently recorded as A+.
- Shared `mobileDrawerOpen` state, plus wheel/scroll-ownership and symbol-formatting regression tests.
- S/R zones now carry `bars_since_touch`; full labels show a compact age suffix (e.g. `· 76b`) only when the last touch is at least 20 bars old. Zone math/selection unchanged.
- Chart indicator preferences persist in `localStorage` (`alphashri_chart_indicators_v1`) across reloads.
- A screen-reader-only S/R summary lists the bands actually drawn (kind, range, touches, recency).

## Changed

- Storybook app widgets now live under App (not Design System); the duplicate PaperTradingTable story was folded into the common TanStackTable page, and all table stories use the shared table component.
- FastAPI route dependants are prebuilt at startup; the cold first-request cost moves to boot.
- Analytical profitability reads tolerate up to 5 stale sessions; chart and replay reads stay at 1.
- Trade analytics now read only projected columns; instrument and live-stream reads are narrowed to the fields actually used.
- Throwaway auth fixtures use cost-4 bcrypt only in scoped helpers (production hashing unchanged).
- Sections tab has a single immediate scroll owner; screener tab strip scrolls at 390px.
- Symbol identity unified via `displaySymbol`/`chartHrefForSymbol`/`tradingViewSymbol` across tables, sector, report, paper trading, alerts and ticker.
- Option contracts display `NIFTY 22900 CE` with the raw symbol in the tooltip; P&L shows the full amount plus percent.
- Ticker uses two-row compact tiles and suppresses the band while a drawer is open.
- Chart page: `F` toggles fullscreen; the fullscreen modal has an "Open full chart page" link.
- CI: failed E2E jobs append a shard/spec/test/error table to the job summary and keep JSON reports with the existing artifacts.
- CI sharding now follows measured durations: frontend unit runs 4 shards on full builds, Python runs 6 shards, and E2E uses a 16-shard file-duration planner; expected PR-to-main wall drops from ~7-10 min to ~4-6 min.
- Frontend unit gate on PRs to develop now runs only changed test files; the full 4-shard suite stays on PR-to-main/nightly. This cut the shared-module changed job from ~5m to seconds while keeping the release gate complete.

## Fixed

- Cold `replay_configs` query 298 → 9.29 ms; chart 232 → 58 ms.
- Fixture-auth wall time 12.2 s → 3.25 s.

- Release E2E repairs: evidence specs use a writable artifact root; narrow chart/options specs target visible affordances; HOME desk mocks `user.sections` and keeps one sector fetch; sector movers subscribe synchronously across rebuilds; patterns URL writes remove stale `hist`; screener symbol text is clickable without the redundant chart icon stealing the target.

The stale dock-scope E2E now matches the shipped contract (a universe switch closes the previous universe's chart).

- `BrokerAuthNotice` is now a warning `Alert` with icon, title, description and an “Open Settings” action (the `Alert` primitive gained an Ant-Design-style `action` slot). Storybook uses the dark manager/docs theme, and app stories render the component alone without the old `DemoPanel`/`Specimen` headings and demo chrome.
