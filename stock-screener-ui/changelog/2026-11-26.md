# 2026-11-26

## Added

- In-memory DB query benchmark harness (`scripts/perf/db_query_bench.py`) with structural tests, so query cost can be measured without touching the live SQLite DB.
- Covering indexes for instruments and replay configs, plus the migration that installs them.
- Regression suites for FastAPI route prebuild, the new DB indexes, and analytics column projections.
- S/R zones now carry `bars_since_touch`; full labels show a compact age suffix (e.g. `· 76b`) only when the last touch is at least 20 bars old. Zone math/selection unchanged.
- Chart indicator preferences persist in `localStorage` (`alphashri_chart_indicators_v1`) across reloads.
- A screen-reader-only S/R summary lists the bands actually drawn (kind, range, touches, recency).

## Changed

- FastAPI route dependants are prebuilt at startup; the cold first-request cost moves to boot.
- Analytical profitability reads tolerate up to 5 stale sessions; chart and replay reads stay at 1.
- Trade analytics now read only projected columns; instrument and live-stream reads are narrowed to the fields actually used.
- Throwaway auth fixtures use cost-4 bcrypt only in scoped helpers (production hashing unchanged).
- Chart page: `F` toggles fullscreen; the fullscreen modal has an "Open full chart page" link.
- CI: failed E2E jobs append a shard/spec/test/error table to the job summary and keep JSON reports with the existing artifacts.

## Fixed

- Fixture-auth wall time 12.2 s → 3.25 s.
- Movers / segment / live-stream DB reads 4.06× / 8.25× / ~7.7× faster.
- App-wide symbol chart dock now shows the expand/fullscreen control; closing the fullscreen modal returns to the still-open dock, and the Escape that closes the modal no longer closes the dock too — a second Escape closes the dock.
- S/R overlay draws at most one support and one resistance band (backend score order); bands extend from first touch to the latest displayed candle with a solid instead of dashed border. `sr` band appears only when neither sided zone is drawable; server-side `chart_patterns/levels.py` computation unchanged.
