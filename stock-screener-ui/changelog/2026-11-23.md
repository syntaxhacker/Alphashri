# Changelog — 2026-11-23

## Added

- **Semantic border tokens** — nine dark border tokens plus light-mode overrides in `src/ui/palette.ts` / `src/tailwind.css` (`subtle`, `default`, `strong`, `focus`, `positive`, `negative`, `warning`, `info`, `disabled`). Surfaces can now distinguish a section separator from a critical error without adding another identical hairline; adopted on the replay workstation, paper-order band, positions panel and add-leg dialog.
- **`Grid` / `Row` / `Col` layout primitives** (`src/ui/layout/Grid.tsx`, new `Row.tsx` / `Col.tsx`, exported from `src/ui/index.ts`) — 12-column responsive layout without JS breakpoint hooks, with `gridPrimitives.test.tsx` coverage.
- **Full-screen replay workstation** — `ReplayPanel` now fills its container (`h-full min-h-0 w-full`) with titled `WorkstationPanel` sections, a two-up chart band (`lg:grid-cols-2`, `min-h-[240px]`, no `max-h`), pinned playback controls and legs, and a centred `EmptyState`. `OptionsReplayPage` splits its title (`size="lg" fw={700}`) from the description.
- **Staggered-leg options paper trading** — a leg can enter an existing open option paper position on a later minute or session (`OptionPaperLeg.entry_ts`, migration `os3a2b3c4d5e`, `POST /api/options-paper/positions/{id}/legs`, a per-leg `active` map, entry-only costs per leg and no lookahead), with an `ADD LEG` dialog in the positions modal.
- **`docs/OPTIONS_PAPER_DESIGN_AUDIT.md`** — re-audit of the options replay / paper-order band / positions / add-leg / dock surfaces: 10 prioritised findings, a type-scale/spacing/surface spec and a `## Fix status (2026-11-23)` section recording what actually landed, what is in flight and what remains.

## Changed

- **Type-scale and gap revamp of the options paper + replay surfaces** — `PaperOrderBand`, `OptionPositionsPanel`, `AddLegDialog` and `ReplayPanel` move to 11px labels, `size="sm"` controls, `gap-1`→`gap-2`/`gap-4`, 8/16px padding, `border-fin-border-subtle` separators and reserved loading/chip slots. The positions panel gains a titled header with a count; the add-leg dialog uses grouped sections with `border-t` dividers. Covered by targeted unit tests (16px padded dialog sections and 11px validation text, titled positions header with a roomy bare table and 11px scroll chip, chart cells growing into the viewport with a 240px floor and no height cap).
- **Replay preview session discovery** — uses the nearest recorded session inside the recorded window, keeps the fallback date with an explanation when no chain is recorded, and surfaces a readable inline error on HTTP 400.

## Fixed

- **10 frontend + 10 backend bug fixes in the options paper / replay lanes** (per the revamp lanes' reports). New backend regression coverage in `tests/api/test_options_paper_bugfixes.py`: colliding CE/PE legs at the same strike get distinct marks and active keys, a leg entered before position entry is refused, a stale concurrent close cannot book trades twice, the booked note stamps the cost version actually used, non-finite close/snapshot/live premiums are rejected or fall back safely, absurd lot counts and expiry values return 400, underlying guards cover provider and service entry points, and `chain_at` reports clear errors for missing history or non-minute times. Frontend fixes cover duplicate-leg detection with mixed-case/numeric strikes, opposite-action legs at the same strike, stale inputs when the parent swaps the position, malformed positions, server leg counts taken from the response, nearest-session discovery and inline 400 errors.
