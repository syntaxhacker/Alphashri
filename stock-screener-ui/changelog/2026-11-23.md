# Changelog — 2026-11-23

## Added

- **Shared typography tier** — `src/ui/typography.ts` + `--text-ui-*` in `tailwind.css` now define one six-step scale (micro 12 / body 13 / label 14 / title 16 / heading 20 / display 24) with a hard 12px floor. `TYPE_CLASS`, `typeSize`, `typeStyle` and `uiTheme.fontSizes` all resolve to it; `scripts/typography-audit.mjs` measures adoption and the Storybook Typography page renders every role. `docs/TYPOGRAPHY.md` documents usage and the migration map.
- **Browser keyboard gate** — `scripts/storybook-keyboard.mjs` runs in CI after the axe gate and walks Modal Tab/Escape/focus return, Tree arrows/expand/select, Menu arrows/Home/End/Escape and Tabs automatic activation.
- **A+ loop contract** — `AGENTS.md` now requires a durable gate, live lane list, 3–5 disjoint agents per wave, per-turn progress reports, integrated evidence, and three independent raters before “done”.
- **Agri release history backfill** — packaged and published the 217 CKAN-seed days (2025-10-27 → 2026-05-31) from the verified local cache into `data-2025-10` … `data-2026-05`, with per-day manifests and SHA256 validation. GitHub release history now has 388 agri daily assets through 2026-11-21; the three known partial daily partitions remain excluded. No prices, MSP or arrivals were invented.
- **Market Screener selectable technical columns** — the table's column picker now exposes EMA/SMA, VWAP, Bollinger, MACD, Stoch, CCI, momentum, ADX±DI, Hull, PSAR, volatility, multi-period returns, recommendation, range/liquidity and fundamental columns. They ride along in the same TradingView scan (`api/market_screen/fields.py`), stay hidden by default, and can be enabled per user. `TableColumnMeta.defaultHidden` keeps the default table narrow while the picker sees every column.
- **Market Screener 1m/5m change columns** — the table now shows intraday 1-minute and 5-minute percentage moves from TradingView `change|1` / `change|5`. The field names live in `api.tv.columns.INTRADAY_CHANGE_FIELDS` on the backend and `src/config/marketIntraday.ts` on the client; the table columns and API mapper are generated from those registries rather than repeating each period.
- **Semantic border tokens** — nine dark border tokens plus light-mode overrides in `src/ui/palette.ts` / `src/tailwind.css` (`subtle`, `default`, `strong`, `focus`, `positive`, `negative`, `warning`, `info`, `disabled`). Surfaces can now distinguish a section separator from a critical error without adding another identical hairline; adopted on the replay workstation, paper-order band, positions panel and add-leg dialog.
- **`Grid` / `Row` / `Col` layout primitives** (`src/ui/layout/Grid.tsx`, new `Row.tsx` / `Col.tsx`, exported from `src/ui/index.ts`) — 12-column responsive layout without JS breakpoint hooks, with `gridPrimitives.test.tsx` coverage.
- **Full-screen replay workstation** — `ReplayPanel` now fills its container (`h-full min-h-0 w-full`) with titled `WorkstationPanel` sections, a two-up chart band (`lg:grid-cols-2`, `min-h-[240px]`, no `max-h`), pinned playback controls and legs, and a centred `EmptyState`. `OptionsReplayPage` splits its title (`size="lg" fw={700}`) from the description.
- **Staggered-leg options paper trading** — a leg can enter an existing open option paper position on a later minute or session (`OptionPaperLeg.entry_ts`, migration `os3a2b3c4d5e`, `POST /api/options-paper/positions/{id}/legs`, a per-leg `active` map, entry-only costs per leg and no lookahead), with an `ADD LEG` dialog in the positions modal.
- **`docs/OPTIONS_PAPER_DESIGN_AUDIT.md`** — re-audit of the options replay / paper-order band / positions / add-leg / dock surfaces: 10 prioritised findings, a type-scale/spacing/surface spec and a `## Fix status (2026-11-23)` section recording what actually landed, what is in flight and what remains.

## Market snapshot freshness

- **Live `/api/market/snapshot` no longer serves stale frames.** With a 5s UI poll against a 5s TTL, the old stale-while-revalidate path made the UI see a new frame only every ~10s. Live requests past the TTL now block on a singleflight TV scan; closed markets keep stale-serve. Measured scan cost is 0.42–0.56s for `nifty50`/`nifty500` and ~1.7s for `all_equity`, so freshness-first is cheap here. Removed the now-unused `MARKET_SCREEN_LIVE_STALE_SEC` knob/`LIVE_STALE_MAX_SECONDS` constant.
- **Verification:** `tests/api/test_market_screen.py` 155 passed (was 156 with one stale-path test removed), plus `test_market_snapshot_columns.py` + `test_market_ticker.py` 38 passed. TDD: the two rewritten freshness tests failed before the source fix.
