Agri assets and older monthly releases are untouched; `--latest` remains the local apply path and `--from/--to` in-month replay of old 52W days is no longer available. Strategy and data math unchanged.
- No DB migration; `db/alphashri.db` was not opened or migrated.
- Unrelated network TLS and thread-local storage untouched.
- Benchmark showed ~24% timed wall reduction with byte-identical pattern output.
- No DB migration; no API restart during tape recording for verification; no agri changes.
- Automatic local release-sync watcher is on by default (`RELEASE_SYNC_ENABLED=1`, `RELEASE_SYNC_POLL_SEC=900`, `RELEASE_SYNC_STARTUP_DELAY_SEC=30`): it dedupes against `reports/refresh_runs.json` and applies newer published agri + 52W assets via `run_sync(mode="latest", allow_empty=True)`, invalidating the screener cache; it never blocks startup and is skipped in `CI_MODE`. Scheduled hourly full-NSE local compute was removed in the single-source refactor; hard refresh stays admin-triggered ("Clear cache + DB" then "Run batch" with Full refresh), and the manual `scripts/sync_refresh_assets.py --latest` CLI still works. No strategy or data-math change.
