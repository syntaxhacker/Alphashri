## Changed

- Chart indicators: shared SMA/Bollinger prefix sums, a plain-float VWAP loop, a uniform-offset ISO timestamp fast path (the pandas parser remains the fallback) and one-pass candle extraction. All 11 enabled timeframes are byte-identical; best-of-run −23.8% median / −34.6% p95 under contention, and −74% on a quiet rerun.
- S/R zones: wire OHLC extracted in one `itemgetter`/`np.fromiter` pass and a running cluster mean without rebuilding an array per touch. Interleaved A/B +16.2% median at 400 bars, cProfile −40%. Pivot detection stays single-source in `features.pivot_indices`.
- Backtest chart payload: column arrays instead of `iterrows`, `bisect` trade-marker lookup and a per-date ORB index. ~3.1× on a 22k-bar payload; six output digests byte-identical.
- Sim bar marshalling: `to_numpy()` + `index.asi8` zip instead of one pandas Series per bar. 7.15× interleaved A/B on 22k bars, 0 field differences.
- Instrument-key resolution: an identity-keyed index replaces per-symbol full-master scans. 40× (`resolve_token`) and 33× (`get_instrument_key`) on 2,000 symbols; 58M → 100k item visits; 46 parity tests.
- Instrument-key index builds are single-flight: 20 concurrent cold callers built the O(N) index 18–20 times; a double-checked class-level lock collapses that to one while cache hits stay lock-free.
- 52W screener: one 90-day daily fetch per row (8 → 4) and one bulk `52w_range:all` load per screen (4 → 1). Touch-history enrichment is 2 SQL statements → 1.
- 52W metadata: rationale is built only for rows that survive the profile gate (85 → 25 in the fixture) and the summary is computed once (2 → 1), with byte-identical output.
- Dashboard sparks: fan-out pool 6 → 16; 2.41× on the measured wait (fixed-latency profile), byte-identical payload.
- CI: the PR path gate now covers `chart_patterns/**`, `backtest/**`, `trading/**`, `cache/**` and root `upstox_trader/**`, so PRs touching only those tested packages run the Python tier instead of skipping CI.
- Value-scan scoring: peer percentile ranks use `bisect_right` on the pre-sorted distributions and each row field is parsed once. 2.9M distribution visits → 0, `_num` calls 102k → 44k, 3.34× median per 2,000-row pass; bit-identical output (SHA-256 across 3 configs × 2,000 rows).
- Options walls: volume-delta windows bisect the already-built epochs list and `_top` is memoised per request by chain identity. `_epoch` calls 2,921 → 539, `_vol_delta` 372 → 0, −18% median / −51% p95; payload hash identical across 12 configurations.
- Sector themes: theme membership is inverted once and the frame walked once instead of one full-frame `isin` per theme. 20 passes → 0, 21 sub-DataFrames → 1, 1.71× median; byte-identical output plus 1,500 randomized differential cases.
- Cache stats: one keyspace `SCAN` replaces one per observed domain (8 → 5 commands with 4 domains; 4 → 3 without the stats flush). Stats output identical; the combined-INFO variant was rejected because fakeredis rejects list sections.
