# 2026-11-25

## Added

- **Native signal sections** in the Market screener and Home desk. A `Sections` tab renders user-defined sections (VWAP reclaim/reject, momentum 1m/5m/15m, volume surge 5m, RVOL spike, 52W touch, EMA cross, ORB proxy) using shared `TanStackTable`; a `Section Manager` modal provides create/duplicate/edit/reorder/delete/pin, JSON import/export, validation and 390px single-column layout. User sections are also offered as windows in Home's `+ Window` picker via dynamic `DockPanelSpec`s.
- New saved-config scope `user.sections` v1 with debounce, hydration latch, immutable upsert/remove and untrusted-input normalisation.
- New `GET /api/sections/scan` (auth, typed response, `sections` tag) backed by one `tradingview_screener.Query` call per market per 60s cache window, with Python predicate evaluation and an `update_mode` live guard.
- `docs/TV_USAGE.md`: verified TradingView library field catalogue, structured-payload → flat-field translation, non-existent fields and measured coverage; `docs/MARKET_SECTIONS_PLAN.md` records the delivered phases.

## Changed

- Section conditions use verified TV flat fields directly (`change|5`, `volume_change|5`, `VWAP`, `relative_volume_10d_calc`, `EMA20/50`, `Volatility.W`, `Perf.W`, `change_abs`, `market_cap_basic`), with null values resolved to concept-supplied references server-side. No indicator math in Solid components and no alias layer.
- Live sections exclude `update_mode != streaming` rows; delayed rows are reported with a count and note. India/BSE duplicates and US non-stock/delayed rows are excluded.

## Fixed

- Integrated the ten implementation lanes: `newSection` import source, `open`/`high`/`low` whitelist for ORB, concept-reference resolution in validation/field selection/predicates, modal test mock for `presets`, and Home picker memo assertions.

A real request now returns 500 rows with correct symbols and 126 matches for a `change|5 > 0` section.

- Section Manager condition values are now explicit `Number | Field | Concept default` sources (field dropdown, concept reference shown read-only) and each editor has a Usage panel describing fields, data family and where the section is used.
