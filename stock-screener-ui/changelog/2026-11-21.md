## Fixed

- **Sub-11px text in the merged panels** — `NiftyFuturesPanel.tsx` and `NiftyItmPeFlow.tsx` (both from #195) shipped `9px` badges and `10px` axis labels, violating the hard 11px floor. Raised to 11px; `reportFontFloorAll` now sees the whole report surface clean.
- **Chart replay clip covered by a test again** — `NiftyChartPanel` clips *every* source at the playhead when one is supplied (replay is orthogonal to the source), so LIVE no longer draws unplayed bars. The old test asserted the pre-fix behaviour (3 bars with a 09:16 playhead) and has been corrected to 2.
- **Stale Index Report tests reconciled with the promoted type scale (11/12/13/17/23) and the single index selector** — the toolbar's duplicate index `Select` was removed during the redesign; several specs still asserted 11/12/15/16 and both selectors. No production behaviour changed for these.
- **HOME desk seed test raced its own lazy chunk** — `HomePage.test.tsx`'s `(seed)` test awaited the market-heatmap panel and then asserted `options-chain-window` **synchronously**. Every desk panel is a `lazy()` chunk behind `PanelSkeleton`, so a settled heatmap says nothing about the options window; on a loaded runner (and whenever the file ran alongside its neighbours) the sibling import had not resolved. It passed in isolation only because the chunk was warm. It was the **single failing test out of 10,950** in the PR-to-`main` full unit job. Now awaited on its own (`findByTestId`), matching the file's own convention. Reproduced deterministically: racy form failed 3/3 with `src/pages/home/` run as a set, fixed form passed 3/3 under the same load.
- **Backtest chart never appeared after a run (real bug, found by the full E2E suite)** — `BacktestChartTabs` read `const sym = props.selectedSymbol` and `const currentChartData = sym ? … : null`, two **non-reactive snapshots taken at mount**. The store's `selectedChartSymbol` starts `null` and is only filled once results arrive, so `sym` stayed `null` forever: the chart area kept rendering `Select a symbol` while the tab strip above it — which reads the prop reactively — showed the symbol as selected and highlighted. Both are now accessors. This is why the unit tests missed it: they mount with a static `selectedSymbol`, so a snapshot read looks correct. Added a test that starts `null` and sets the selection after mount (proven RED on the old code, GREEN now); `tsc` moved 322 → **321** because the non-null assertion it needed is gone.
