## Added — all ten Movers become table presets

The Market table and the Movers tab were **two separate TradingView scans of the same
universe**. The Movers cards needed fields the market snapshot did not carry, which is
why they could not be presets. Now one scan serves both.

**Backend:** 7 columns added to the market scan (`volume`, `average_volume_10d_calc`,
`gap`, `ATR`, `high`, `low`, `Value.Traded`), and three ratios derived server-side so
the client never divides two nullable operands: `to_52w_high_pct`, `from_52w_low_pct`,
`range_vs_atr`. Each guards a zero/missing divisor and returns `None` rather than
`inf`/`NaN`. Row count is 46 fields (was 36).

**Measured payload** at the 4,000-row cap: JSON 2.59 MB → 3.49 MB (**+34.9%** raw),
13.1 KB → 17.6 KB gzip (**+34.3%**); columnar wire +43.2% raw / +41.8% gzip. Same order
as the earlier value-field widening, and it replaces a *second* full scan (`/api/screener/dashboard`),
so net request volume does not rise.

**Frontend:** ten `MOVER_PRESETS` — Top Gainers, Top Losers, Near 52W High, Near 52W
Low, Volume Surge, Most Active, Top Turnover, Gap Up, Gap Down, Range Expansion — each
a `{filters, sort}` pair in a collapsed "Mover presets" band, producing removable chips.

### Thresholds copied from `dashboard.py`, including where the brief was wrong

The brief assumed Gainers/Losers/Range Expansion had numeric gates. `dashboard.py` sorts
those with **no threshold**, so they are pure top-N sorts and the presets say so. The
seven real thresholds (`-5.0 ≤ to-52W-high ≤ 0.5`, `-0.5 ≤ from-52W-low ≤ 5`,
`relvol ≥ 3`, `gap ≥ +3`, `gap ≤ −3`) match verbatim.

### The market-cap floor the first pass missed

Every preset now carries `mcapMinCr: 500`, because the Movers dashboard defaults to
`min_market_cap_cr = 500` and its boards never show nano-caps. Without it the presets
were **not** a mirror: measured live, `gap ≥ 3` matched **132** rows across all 3,593 but
only **9** with the floor — the other 123 were ₹346–491 Cr micro-caps. After the fix the
Gap Up preset returns 9, matching the tab, with both chips visible (`MCap ≥ 500 Cr`,
`Gap ≥ 3%`).
