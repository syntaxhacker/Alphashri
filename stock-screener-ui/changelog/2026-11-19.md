# Changelog — 2026-11-19

## Added
- **Reusable report-visualisation library** (`scripts/market/report_viz/`) — **57 instrument-agnostic chart builders across eight families** (29 initial + 28 phase 2). Phase 2 adds positioning/participant flow (including the previously missed **CE vs PE net positioning**), replay/3D terrain/IV/futures, and vol-decay/cross-market/anatomy charts. Initial 29: pin/spot/walls, gamma/GEX, futures, flow/volatility and tape/3D/timeline. `InstrumentSpec` carries currency, price precision, strike step, lot, OI/value units and session window, so NIFTY, SENSEX and stock reports use the same code; nothing is hardcoded to 25,000/50/₹/09:15–15:30. The flagship `gamma_flip_gex` keeps `net_gex` (all strikes) and `regime_gex` (cumulative ≤ spot) as separately labelled series. Shared `panel()`/`render_page()` + `assets/core.js` dispatch, palette, tooltip, resize, null-gap and Plotly helpers; existing report generators/HTML untouched.
- **Phase 2 chart families** — `positioning.py` (10: CE vs PE net positioning, divergence, PE OI heatmap, window bars, volume-vs-OI bubbles, participant class stream/heatmap, focus, strike terrain, wall ladder), `replay3d.py` (7: positioning terrain, IV surface, futures path, replay heatmap, PE focus, top-volume strikes, event ribbons), `volcross.py` (11: PE premium ribbon, four-clock smile, premium/intrinsic, theta, skew, basis 3D/strip, lead-lag, cross-index, quadrants, event study).
- **Reusable chart gallery** (`scripts/market/report_viz/demo/build_demo.py`) — a synthetic, clearly labelled fixture (NIFTY; `--sensex` supported). The main gallery now has **30 panels including the requested CE vs PE net positioning chart**; a separate fixture-backed 29-panel phase-2 page was used for the wider visual smoke. Neither is market data.
- **`/home` floating-window desk** — an absolute-positioned canvas (an explicit exception to the no-fixed-height flex rule: it is a coordinate space, not a flex pane). Windows drag by the title bar, resize from all eight edges/corners, raise on focus (z-order), minimise/maximise, pop out to a standalone snapshot page, and recover off-canvas windows with **Fit all windows**. A lock toggle disables drag/resize/keyboard sizing. Named layout tabs (Main / Blank / Macro, `+ New screen`) persist through saved-config scope `window.home`; saved rects are clamped and unknown panel types dropped on read. First visit seeds a populated Main desk rather than an empty canvas.
- **Five real dockable panels** registered for the desk — market heatmap, sector heatmap, options chain, paper positions, news feed — each self-contained (own store/hook) with explicit loading / empty / error states rather than placeholder text. All five mount through the same `DockPanelSpec` the pages use; no panel is a stub.
- **`src/components/dock/`** — a panel contract (`DockPanelSpec`: reactive `data`, optional `commands`, `minWidth`/`maxWidth`, `requires`) plus a generic split-pane host that distributes space by `size` and drops the splitters below 1200px. Proven on the real, unmodified `NiftyChartPanel` via `reportChartDock.tsx`, not a mock.
- **Sector store hoist** (`src/state/sector.ts`) — sector page state moved out of the component so a dock panel can read/write it; polling is owned by the store and torn down on unmount. The `market.heatmap` + `sector.heatmap` panels are the real consumers that made the hoist necessary.
- `tests/e2e/home-desk.spec.ts` — /home E2E coverage (network mocked at the boundary).
- **Window-manager perf probe suite** (`src/components/window/perfProbe.test.tsx`) — 60-event drag/resize, focus/z-order remount and minimise/poll-teardown probes.

## Changed
- **Market map tint is cividis** — 17 CVD-optimised sequential stops with strictly monotone luminance, one ramp for every metric. The colour domain is the raw min/max clamped to a robust median/MAD window, so a single +12,026% print saturates at the yellow end instead of flattening the rest into two colours; clean distributions keep byte-identical fills. Both legends print the active metric, the clamped bounds and "low → high · position in range, not gain/loss" (cividis has no zero anchor, so hue is not gain/loss).
- **`etf` is a cap tier of its own** — a class outside the size ladder, carrying a null market cap. The "ETF only" toggle was removed and its `etfOnly` state deleted from the frontend (a saved `etfOnly:true` is dropped on read rather than becoming a hidden filter); `micro` is micro-cap equity again, not "not a company".
- **`all_equity` includes ETFs** — the TradingView query now asks for `type in ["stock", "fund"]`, so NSE funds such as GOLDBEES / LIQUIDBEES / NIFTYBEES are no longer invisible. (Old docs still quote the ~3,229 stock-only row count.)
- **Window drag/resize commits on pointer-up** — in-flight geometry lives in one signal, so a 60-move drag performs no layout commits, no sibling re-renders and no panel remounts until release, then one commit: ~60 saved writes per drag → 1.
- **HOME toolbar** reduced to the panel picker, layout tabs and DESK controls; the symbol/expiry inputs are gone — the desk supplies one fixed context.

## Fixed
- **Reusable pin panels rendered axes but no series** — `pin.js` returned a bare frame object as `c` while every path used `c.text`/`c.amber`; D3 removed those undefined stroke attributes. The frame now carries the palette too. Found by reading the 1600/390 PNGs, not by the 111 green tests; kept as a visual regression check.
- **CE vs PE net-positioning spot path emitted `MNaN`** — `positioning.js` passed already-projected band-scale x values through the scale again; the shared `linePath` now accepts both labels and pixels. Found by the 1600/390 screenshot read-back, not by the 208 green tests.
- **Gamma-flip axis printed two clocks on top of each other** — the final tick was always appended even when it collided with the previous one; `core.js timeTicks` and `gex.js sampleIndices` now only add the last label when it has room. The narrow GEX summary was shortened so it no longer runs off the panel.
- **Test-suite deadlock** — `test_user_configs.py` hung in fixture teardown: each of **131 tests** entered the full production lifespan, whose event-radar task issues a `to_thread` SEC-EDGAR request (30s timeout); cancelling the task cannot cancel the thread, so `asyncio.run`'s executor shutdown joined it. The shared `client` / `auth_client` fixtures no longer enter the lifespan per test — they construct `TestClient(app)` without the context manager — making teardown effectively free.
- **Five lifespan tasks were never cancelled at shutdown** — `_event_radar_task`, `_nifty_futures_task`, `_sensex_futures_task`, `_options_recorder_task`, `_tick_tape_task` (seven others were). A restart could block up to one socket timeout each. All five are now cancelled and awaited through `_shutdown_cancel_and_wait` with a 5s budget; `tests/api/test_lifespan_shutdown.py` guards the helper and asserts the lifespan references every name.
- **Chart re-mount on focus/z-order and panel remounts during drag** — the window panel spec is now a memo with reference equality, so focus, sibling drags and save echoes reuse the same spec instead of rebuilding the panel canvas. The perf probe asserts mounts stay flat (2) across focus/z-order/keyboard-move and a 60-event drag.
- **Market E2E fixtures** — ETFs are now `cap_tier: "etf"` with `market_cap_cr: null`; previously they sat under a size tier with a real market cap, so the new ETF tier matched none of them.

## Fixed (report chart and colour)
- **The Index Report chart rendered 30px tall inside a 300px panel.** `LocalCompactPanel` never emitted `data-compact-card-content`, but `NiftyChartPanel` styled its body through `[&_[data-compact-card-content]]:flex-1` — a selector inherited from the Mantine `CompactCard` it replaced. The attribute is now emitted and the body owns `flex-1 min-h-0`; chart 30px → 329px at the same panel height, and all 49 report panels get the fix at once.
- **Index Report candles were painted `#FFFFFF`** — `MARKER_BORDER` (the white *outline* for entry/exit markers) was used as the bullish body fill, and a near-black `SCALE_BLUE[6]` as the bearish one, so a bullish candle rendered as a solid white block on the black chart. Both charts now use `POSITIVE`/`NEGATIVE`.
- **A token 1-minute merge hid the whole session** — pre-market the chain feed carries two stray spot minutes while the EOD series holds every bar; the merge won on row count and drew one giant candle. `pickFreshestCandles` now compares *covered span*, and the session pin falls back to the data's newest session only when the calendar-gate session has no rows. An explicit `report.date` (replay / EOD / previous-day) is never second-guessed — the panel tests caught that regression before it shipped.
- **91 sub-10px font sizes across 16 report files** — `REPORT_FONT.micro` 10 → 11 and every 7.5/8/8.5/9px literal removed, guarded by `reportFontFloor.test.ts` so the floor cannot silently drop again.
- **Colour semantics on the report** — raw OI is no longer green/red (the repo forbids directional colour on OI; it now uses the same CE/PUT level tokens `LevelsInPlay` already used, so two panels stopped disagreeing about the same number); the OI tint derives from a palette token instead of hardcoded `rgba()`; and a level "AT" spot is side-aware, so a put wall at spot reads green support rather than red resistance.
- **429 rate limits were indistinguishable from failures** in options positioning — now `data-kind="rate_limited"` with a retry countdown from `Retry-After` (falling back to the existing default), instead of "failed" + an enabled Retry that prolonged the block.
- **Duplicate panel fetches** — two chain / positioning / rotation windows and two market heatmaps each fetched the same key twice. An in-flight dedupe keyed on every response-changing parameter measured 2 → 1 for all four groups, with a ref-counted `AbortController` so closing one window cannot cancel a flight another still awaits.
- **Windows re-rendered on unrelated changes** — `patch`/`close`/`raiseToFront`/`maximize` now preserve `WindowState` identity for untouched windows and the settings slot is memoised: 16 slot calls per focus change (all 8 windows) → 1.

## Data / Ops
- **"· live (WS)" was shown during an outage** — the header appended it whenever the market was open, so it sat beside the `STALE Nm` badge asserting both at once. It now says `· reconnecting` while stale. Nothing tested this label, which is why it shipped.
- **"Updated" meant fetch time, not data time** — `markUpdated()` stored `Date.now()`, so a payload that arrived a second ago read as current even when its newest bar was hours old. `updatedAtMs` now seeds from `market.as_of` (fallback `fetched_at`), both carried by the payload and verified distinct: `as_of` 15:39:56.42 vs `fetched_at` 15:39:56.40 vs `snapshot_at` 15:39:57.79.
- **A fresh `fetched_at` masked a stale tape** — the badge took `max(report, tape, burst)`, so a fresh fetch won over a tape that stopped hours ago. Tape age is now the authority (`dataFreshness`, previously dead code). The 90s WebSocket signal is a different thing and is relabelled `WS DOWN 1m` so it no longer contradicts a fresh `DATA 0s` badge.
- **`fetchNiftyExpiries` / `fetchOptionsExpiries` returned `[]` on failure** — an expired token rendered as "No expiries listed", a truthful-looking lie about the exchange listing. They now throw `ApiError`; the panel shows an error with Retry. A test that asserted the old `[]` was updated — it had encoded the bug.
- **Correlation matrix in a dock window was a 100×520 sliver** — ECharts latched the element size at `init` and only resized on `window.resize`, so a window resized after mount kept its first size. Fixed label margins also reserved 180px of a 285px container. Both now observe their own element and scale margins to it; the panel lays its two charts side-by-side above 520px. Live: matrix 100×520 → 285×319 inside a 333px box, nine sector labels readable.
- **A desk arranged at 1600 was unusable at 390** — windows are stored in canvas pixels and nothing re-fit them on shrink, so three 583px windows sat in a 358px canvas and could not be grabbed back. `fitAllToScreen` no longer floors at the interactive drag minimum (which made the scaler a no-op), and a shrinking viewport re-fits — tiling to a single non-overlapping column below 620px. Verified at 390×844: `overlap: false`, `allInside: true`.
- **Keyboard access on the desk** — windows are labelled `region`s, focus carries a non-colour cue plus an amber ring (6.88:1 from palette tokens), move/resize and every desk action announce through live regions, and the preset menu restores focus on Escape. Verified live: ArrowRight moved a window 220 → 230px and announced "SECTOR PERFORMANCE moved to x 66, y 56".

- **Report-viz acceptance** — `.venv/bin/python -m pytest scripts/market/report_viz/tests -q -p no:xdist` → **208 passed**; `node --check` on all eight chart assets; gallery at **1600 and 390** and a 29-panel phase-2 smoke page: no horizontal overflow, no `RV.error` panels, **0 console/page errors**, and a real PNG read-back (not just a DOM count). The screenshots caught the pin-frame, GEX label and CE/PE `MNaN` defects above.
- **CPU/orphan lesson recorded** — a stranded vitest worker held 8.4 GB and pushed the 8-core box to 3% idle / load 72, silently turning every other gate into a timeout. `AGENTS.md` and `SUBAGENT_RULES.md §8.0` now require checking idle CPU before any fan-out run (≥30% idle floor, wait and re-check below it) and `pgrep -af "vitest|pytest|playwright"` after any cancelled/failed run to catch orphaned workers; never run two full suites concurrently or raise Playwright `--workers` past what idle CPU can absorb.
